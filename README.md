# Zyroo - Local Delivery & Fleet Logistics Management Platform

A modern, responsive, full-featured React application designed to streamline local logistics, regional delivery management, order tracking, and real-time dispatch operations.

## Features

* **Interactive Multi-Page Routing**: Powered by `react-router-dom` with active tab navigation states for seamless navigation across Home, Dashboard, Orders, Order Details, and Tracking.
* **Live Dashboard Metrics**: Real-time summary cards tracking total orders, pending assignments, active couriers, and on-time delivery percentages.
* **Comprehensive Order Management**: Search, filter by status, view detailed order logs, and assign couriers instantly.
* **Granular Order Details & Telemetry**: Deep-dive tracking into customer information, delivery routes, and cryptographic custody timelines.
* **Live GPS Tracking**: Consignment tracking simulation featuring corridor route progress bars, rider telemetry, and checkpoint history.
* **Responsive Layout**: Designed with Tailwind CSS for optimized viewing across smartphones, tablets, and desktop workstations.

---

## Tech Stack

* **Frontend Framework**: React
* **Routing**: React Router DOM
* **Styling**: Tailwind CSS
* **Icons & Assets**: SVG iconography and custom image modules

## Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/umarazlan/zyroo-local-delivery.git
   ```

1. Install dependencies:
    ```bash
    npm install
    ```
2. Run the development server:
    ```bash
    npm run dev
    ```

Deployment on Netlify:
    ```
    https://zyrooriding.netlify.app/
    ```
